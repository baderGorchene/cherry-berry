# Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** People export a design as PDF (print or digital), PNG, JPG, SVG, GIF, PPTX or `.cherry`, after a preflight that flags problems and lists the credits their visuals require.

**Architecture:** One server-side renderer draws a page onto a skia-canvas 2D context (vector for PDF/SVG, raster for PNG/JPG/GIF/PPTX parts); text is laid out by Konva's own `Konva.Text` (Konva's skia backend), so line breaks match the editor. Format writers wrap that renderer. Preflight is a pure function in `@cherry/doc`, fed by a small server endpoint that reports which fonts the server can render and the license/size/availability of every visual the design uses. `.cherry` is serialized in the browser from the live Yjs document.

**Tech Stack:** skia-canvas 3 (MIT), konva 10 skia backend (MIT), gifenc (MIT), pptxgenjs (MIT), fflate (MIT), Inter + Space Grotesk font files (OFL-1.1, see Decision 2), Fastify, React.

**Spec:** `docs/superpowers/specs/2026-11-11-cherry-berry-design.md` (Phase 7: "Export — PNG/JPG/SVG/PDF/GIF/PPTX/`.cherry`, preflight checks, attribution notes"). Screen: "Export & preflight" in the design canvas (format cards, options, Preflight side panel, Cancel / Export).

## Decisions

1. **Render on the server, synchronously.** `POST /api/designs/:id/export` renders and returns the file in the response. No pg-boss queue: skia-canvas encodes on its own thread pool, a design is a handful of pages, and limits (Global Constraints) bound the work. Cost if wrong: a queue later; the service function stays the same.
2. **Bundle Inter and Space Grotesk font files on the server.** The spec mandates both fonts and the editor already loads them; the server needs the files to render without the network (self-host). They are OFL-1.1, which permits redistribution; the dependency-license rule is about code. Use `@fontsource/inter` and `@fontsource/space-grotesk` (weights 400–700, latin + latin-ext) if skia-canvas `FontLibrary.use` accepts woff2; otherwise `@expo-google-fonts/inter` and `@expo-google-fonts/space-grotesk` (TTF). Georgia, Arial, Times New Roman and Courier New are not bundled: preflight warns and skia substitutes.
3. **Print PDF is RGB.** It adds the document's bleed and optional crop marks. CMYK, ICC profiles, PDF/X and spot plates belong to Phase 9's print service; the dialog says so in one line and preflight warns on CMYK pages.
4. **Multi-page PNG/JPG/SVG download as one `.zip`** (fflate); one page downloads as the bare file. PDF, GIF and PPTX are always one file.
5. **GIF = one frame per exported page**, looping forever; "Seconds per page" 1–10, default 2. Animated GIF visuals export as their first frame.
6. **PPTX keeps text editable.** Per node: text → text box, rect → (rounded) rectangle, ellipse → ellipse, image → picture, path and group → a PNG of that node at 2×, placed at its box. Rotation and opacity carry over. Slide size = the first exported page; other pages are scaled to fit and centred. Each slide's speaker notes hold the credits for that slide's visuals.
7. **`.cherry` is exported whole, in the browser**, from the live document (`yToDoc` + `serializeCherry`); visuals stay referenced by asset id. It works offline. A bundle with the image files is out of scope (no importer exists yet).
8. **Everyone who can open the design can export it, viewers included.** Visuals the user cannot read (`canReadAsset` false, deleted beyond reach, or a foreign id) render as the editor's grey "Image unavailable" placeholder and are reported unavailable.
9. **Export waits for "Saved".** The server exports the live document; the dialog disables the Export button while the editor status is `saving` ("Saving your latest changes…") or `offline`/`error` ("Export needs a connection."), except for `.cherry`.

## Global Constraints

- Every dependency must be MIT, Apache-2.0, BSD, ISC or MPL-2.0; check before adding (font files: Decision 2).
- Text color contrast ≥ 4.5:1. `#8E1EA2` is the only palette color allowed for body text on white; `#C654C3` only for large text and icons; `#ED96D7` and `#FFC0DE` are backgrounds only. Neutrals: ink `#22142A`, muted `#5D4E66`, line `#E9DFEC`, surface `#FBF7FC`; status: success `#1E7A46`, warning `#B45309`, error `#B3261E`.
- Fonts: Space Grotesk (headings), Inter (body).
- No AI features available to the user.
- Units: page geometry is in the page's unit; `toPx(v, unit)` gives CSS px (96/in); text `fontSize` is in pt (`PT_PX`). PDF canvases are in points: 1 px = 0.75 pt.
- Limits: a raster page may be at most 8192 px on each side and 40 million px after scale; at most 100 pages per export; otherwise 400 `export_too_large`. Rate limit 20 exports per user per minute (429 `rate_limited`).
- Errors: `HttpError(status, code)` on the server, `ApiError` on the web; never a 500 for bad input.
- AGENTS.md: routes parse and authorize only, logic in `service.ts`; never hand-edit `pnpm-lock.yaml` (use `pnpm add`); `pnpm typecheck` and `pnpm test` pass before each commit. E2E runs on ports 3101/5181 only.

## Review Focus

1. **Someone exports right after an edit.** The file shows the edit: the dialog waits for "Saved", and the server reads the live document, not the last stored row. Test in Task 3: `export reads the live document`.
2. **A design uses a font the server doesn't have (Georgia, or a kit font that was deleted).** Preflight warns by name and the export still succeeds with a substitute. Tests: Task 1 `fonts check names missing families`; Task 3 `unknown font still exports`.
3. **A visual is deleted, private to someone else, or a hand-written foreign id.** The export succeeds, draws the grey placeholder, leaks no bytes of the private file, and preflight lists it as unavailable. Test in Task 3: `unreadable visual renders the placeholder`.
4. **A huge page or a high scale.** A 5000 mm poster at 3× is refused with `export_too_large` before rendering, never an out-of-memory crash. Test in Task 3: `oversized raster export is refused`.
5. **A title with slashes, quotes or non-ASCII letters.** The download gets a safe filename (`Content-Disposition` with an ASCII fallback and `filename*=UTF-8''…`). Test in Task 3: `filename is safe for any title`.

### Task 1: Preflight and credits (`@cherry/doc`)

**Files:**
- Create: `packages/doc/src/preflight.ts`, `packages/doc/test/preflight.test.ts`
- Modify: `packages/doc/src/index.ts` (export it)

**Interfaces:**
- Produces:
  ```ts
  export type ExportFormat = "pdf-print" | "pdf" | "png" | "jpg" | "svg" | "gif" | "pptx" | "cherry";
  export type ExportAsset = { id: string; title: string; license: "cc0" | "cc-by" | "own" | "workspace-only"; attribution: string;
    width: number; height: number; kind: "image" | "gif" | "svg"; available: boolean };
  export type CheckId = "fonts" | "bleed" | "safe-area" | "resolution" | "licenses" | "color";
  export type PreflightCheck = { id: CheckId; status: "pass" | "warn"; title: string; detail: string; nodes: { pageId: string; nodeId: string }[] };
  export function usedAssetIds(pages: Page[]): string[];           // image nodes at any depth, hidden ones skipped, each id once, in page order
  export function preflight(doc: CherryDocument, opts: { format: ExportFormat; pageIds: string[]; scale: number },
    env: { fonts: string[]; assets: ExportAsset[] }): PreflightCheck[];
  export function creditsText(assets: ExportAsset[]): string;      // "" when nothing needs credit
  ```

Rules (only the exported pages, hidden nodes skipped, children of groups included):

| id | runs for | warns when | title (pass / warn) | warn detail |
|---|---|---|---|---|
| fonts | all but `pptx`, `cherry` | a text node's `fontFamily` is not in `env.fonts` | "Fonts available" / "Font substituted" | `Georgia isn't on this server, so it will be replaced.` (families joined with ", ", "isn't"/"aren't") |
| bleed | `pdf-print` | any exported page has `bleed === 0` | "Bleed covered" / "No bleed" | `Printers usually need 3 mm of bleed. Set it in the page settings.` |
| safe-area | `pdf-print` | a top-level text node (or a top-level group containing text) has its box within 5 mm of the trim | "Text inside safe area" / "Text near the edge" | `{n} text layer(s) sit less than 5 mm from the trim.` |
| resolution | all but `cherry`, skipping `svg` assets | `asset.width / (toPx(node.width, unit) / 96)` < required ppi: `pdf-print` 300, `pdf` 150, `png`/`jpg`/`gif` 96 × scale, `svg`/`pptx` 96 | "Images sharp" / "Low-resolution image" | `"studio-photo.jpg" is 180 ppi at this size. 300 ppi is recommended.` (first offender; `and {k} more` when several) |
| licenses | all | an asset is unavailable, or `workspace-only` | "Licenses & attribution" both | pass: `{n} CC BY visual(s): credit added to export notes` or `No credits needed`; warn: `"{title}" is unavailable and will show as a placeholder.` / `"{title}" is licensed for use inside this workspace only.` |
| color | all but `cherry` | any exported page has `colorMode === "cmyk"` | "Colors" / "Exported as RGB" | `CMYK, PDF/X and spot colors come with the print service.` |

Checks that don't run for the format are omitted. `nodes` lists every offending node (empty on pass). `creditsText`: one line per `cc-by` asset, `"{title}" by {attribution}, CC BY 4.0`, joined by `\n`, in input order.

- Produces:
  ```ts
  // render.ts
  export type Images = Map<string, import("skia-canvas").Image | null>; // null = unavailable → placeholder
  export function pagePx(page: Page): { width: number; height: number; bleed: number }; // CSS px
  /** Draws the page with (0,0) at the trim's top-left, in CSS px; the caller sets the transform. Background fills trim + bleed unless `background:false`. */
  export function drawPage(ctx: import("skia-canvas").CanvasRenderingContext2D, page: Page, images: Images, opts?: { background?: boolean }): void;
  /** One node alone on a transparent canvas at `scale`, sized to its box (for PPTX). */
  export function nodePng(node: CherryNode, page: Page, images: Images, scale: number): Promise<Buffer>;
  export function loadImages(ids: string[], read: (id: string) => Promise<Uint8Array | null>): Promise<Images>;
  // fonts.ts
  export function registerBuiltInFonts(): void;                 // once per process; Inter + Space Grotesk 400–700
  export function useKitFonts(fonts: { id: string; family: string; format: string; bytes: () => Promise<Uint8Array> }[]): Promise<void>; // cache under os.tmpdir()/cherry-fonts/<id>.<format>, register once per id
  export function availableFamilies(kitFamilies: string[]): string[]; // "Inter", "Space Grotesk", plus kit families
  ```

Drawing must match the editor's `NodeView` (`apps/web/src/editor/Canvas.tsx`): position/rotation as `toKonvaAttrs` (rotate around the box centre), node opacity multiplied down through groups, paint opacity from `Paint.opacity`, rect `cornerRadius`, ellipse inscribed in the box, path `d` via `Path2D` with `fillRule`, stroke width, image stretched to the box, and the placeholder (`#D9D2DC` box, "Image unavailable" in `#5D4E66`, font size `max(1, min(w,h)/6)`, centred). Text: create a `Konva.Text` (import `konva/skia-backend` first) with the editor's `konvaFont` attributes (font size `fontSize * PT_PX / UNIT_PX[unit]`, `fontStyle: String(fontWeight)`), read its `textArr` lines, and draw each with `fillText`, honoring `align`, `letterSpacing` and `lineHeight` exactly as `Konva.Text` positions them.

  ```ts

  export type Out = { bytes: Uint8Array; mime: string; ext: string };
  export function writePdf(pages: Page[], images: Images, print: boolean, cropMarks: boolean): Promise<Out>;
  export function writeRaster(pages: Page[], images: Images, kind: "png" | "jpg", scale: number, transparent: boolean, base: string): Promise<Out>; // zip when >1 page
  export function writeSvg(pages: Page[], images: Images, base: string): Promise<Out>;   // text outlined; zip when >1 page
  ```

- Routes:

  - `POST /api/designs/:id/export` body `ExportBody = { format: Exclude<ExportFormat,"cherry">; pageIds: string[] (1–100, each a page of the doc, else 400 invalid_pages); scale?: 1|2|3 (default 1); transparent?: boolean; cropMarks?: boolean (default true); secondsPerPage?: int 1–10 (default 2) }` → the file, `Content-Type` = mime, `Content-Disposition: attachment; filename="<ascii>"; filename*=UTF-8''<encoded>`. Rate limit per Global Constraints.

PDF: one PDF page per exported page via skia-canvas `newPage`. Digital: trim size. Print: trim + 2 × bleed, plus 8 mm per side when `cropMarks`; marks are 0.25 pt black lines along each trim edge, running from bleed + 2 mm to bleed + 8 mm outside the trim. JPG quality 0.9, white behind transparency. Filename base: title trimmed, characters `/\:*?"<>|` and control characters replaced by `-`, empty → `design`; raster/SVG zip entries `<base>-<page number>.<ext>`.
